DALO

Landing page de una plataforma que conecta clientes con profesionales de oficios. Presenta dos recorridos, categorías de servicios y vistas de la experiencia móvil.

  • Angular 20
  • TypeScript
  • CSS
  • Responsive UI

MI APORTE

Desarrollo de la landing y sus interacciones, con una presentación diferenciada para clientes y profesionales.

SOBRE ESTA VISTA

Adaptación interactiva del proyecto para este portafolio, con sus recursos visuales originales. Las interacciones son demostrativas.

SIN DUDAS

Preguntas frecuentes.

¿Cómo se presenta la confianza?

La interfaz propone perfiles con verificación, especialidades y reseñas para facilitar la comparación. En esta muestra se usan los perfiles ilustrativos de la landing.

¿Puedo contratar desde esta vista?

Esta es una demostración del frontend dentro del portafolio. No genera solicitudes, contrataciones ni pagos reales.

¿Qué cambia para un profesional?

El recorrido se enfoca en presentar sus especialidades, construir un perfil y encontrar oportunidades cercanas.
